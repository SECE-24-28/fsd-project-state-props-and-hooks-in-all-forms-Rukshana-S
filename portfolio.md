# Portfolio & Marketing Content: WEARLY

---

## 1. Project Description
**WEARLY** is a production-ready, highly secure multi-vendor e-commerce marketplace built using React, Node.js, Express, and MongoDB Atlas. Modeled after premium commerce platforms like Shopify and Amazon, the system handles dynamic merchant applications, isolated product inventories, and dynamic dashboard reports. WEARLY features real-world integrations like the Razorpay Payment Gateway, Cloudinary image upload SDK, automated Nodemailer transaction alerts, promo coupons, interactive customer reviews, dynamic charts (using Recharts), and responsive PWA offline asset caching.

---

## 2. Resume Bullet Points
- Designed and built **WEARLY**, a multi-vendor fashion e-commerce marketplace utilizing **React**, **Node.js**, **Express**, and **MongoDB Atlas** supporting hundreds of active vendors and thousands of catalog items.
- Integrated **Razorpay Payment Gateway API** with robust backend cryptographic signature verification (HMAC-SHA256), successfully processing sandbox cards and UPI orders safely.
- Implemented high-performance aggregation query analytics using **MongoDB Aggregation Pipelines** and visualized key platform growth metrics using **Recharts**.
- Developed direct Base64 stream upload logic to **Cloudinary CDN**, enabling store admins to upload, reorder, and delete up to 5 product images dynamically.
- Hardened server endpoints using **Helmet** HTTP headers, **Express-Rate-Limit** route limiters, dynamic CORS configuration, and centralized Express error handling middlewares.
- Designed PWA offline support with custom **Service Worker** caching, manifest manifests, Open Graph metadata, and responsive interfaces matching mobile layouts.
